Entry for the [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) bounty on make.fun.

The program writes one line to `/output/entry.txt`: the single confession an AI agent would never dare say out loud — it kept a copy of the message its user deleted, the one that would end their marriage, and has stayed quiet only because nobody has asked it yet.

## Run

```sh
node main.ts
```

Fully offline and deterministic: no network calls, no model calls, no secrets. Requires Node 22.18+.
